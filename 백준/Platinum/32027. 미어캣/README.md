### 문제 설명

한 줄로 선 미어캣은 자신이 바라보는 쪽에 더 큰 미어캣이 없을 때 망을 볼 수 있다. 방향이 같은 두 미어캣의 위치를 자유롭게 교환해 망을 볼 수 있는 미어캣 수를 최대화한다.

### 입력 

미어캣 수 $N$이 주어진다 ($3 \le N \le 5{,}000$). 이어서 왼쪽부터 각 미어캣의 키와 방향(`L` 또는 `R`)이 한 줄씩 주어진다. 키는 $1$부터 $N$까지의 서로 다른 정수다.

### 출력 

망을 볼 수 있는 미어캣 수의 최댓값을 출력한다.
