### 문제 설명

사진가 $N$명이 한 줄로 서 있고, 최종 순서에서 $k$번째 사진가는 $k$번 명당을 사용한다. 처음에 $i$번째로 서 있던 사진가는 번호가 $A_i$ 이하인 명당만 사용할 수 있다. 이웃한 두 사람의 순서를 바꾸는 연산으로 모두의 조건을 만족시키는 데 필요한 최소 교환 횟수를 구한다.

### 입력 

테스트 케이스 수 $T$가 주어진다. 각 케이스는 $N$과 처음 줄 순서에 따른 $N$개의 정수 $A_1, \ldots, A_N$으로 이루어진다. $1 \le T, N \le 300{,}000$, $1 \le A_i \le N$이며, 모든 케이스의 $N$을 더한 값은 $300{,}000$ 이하이다.

### 출력 

케이스마다 최소 교환 횟수를 한 줄에 출력한다. 조건을 만족하는 순서가 없으면 `-1`을 출력한다.
